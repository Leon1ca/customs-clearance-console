# 关单核验台 v1.7.0 更新说明

## 2026-09-08：列表导出

- 新增“列表导出”，位于“开始识别”和“列表清理”之间。
- 将本批全部文件导出为 Markdown 表格，单份关单分别列出单号、收货人、合同协议号、分项价格及按币种分别列出的总价；关单之间以横线分隔。
- 长信息采用独立双列表格并完整保留；分项表格金额右对齐，源码列宽随内容增长。Markdown 阅读器按自身窗口宽度换行或横向滚动。
- 导出包括全部分页、筛选隐藏的记录和重复文件；无记录、识别进行中禁止导出。
- 未确认分项保留识别金额及复核金额并注明未计入总价，旧记录缺少分项时提示重新识别。
- 移除“详情”列和对应弹窗，逐项校对信息迁移至导出文档。

## 核验流程

- 点击“校验”后，程序打开报关单状态查询页并自动填写报关单号。
- 用户只需输入验证码并点击查询；程序自动检测页面结果是否稳定显示，并自动保存长截图。
- 90 秒内未检测到稳定结果时，启用“立即截图”作为兜底，不会阻断人工操作。
- 截图完成后使用应用内轻提示，不再弹出 Windows 消息框要求再次确认。

## 界面

- 目录设置、关单清理、截图清理、开始识别、列表清理改用统一扁平图标，并提供 24、32、48 像素资源适配不同 DPI。
- 右键菜单精简为“复制选中的内容  Ctrl+C”。
- 总览标题字号高于金额字号；金额采用常规字重，空值符号仍使用强调样式。
