# UI 设计与边界规则

## 布局

- 主窗口最低 1100×720，使用 `TableLayoutPanel` 和 DPI 缩放，不依赖跨区域绝对坐标。
- 顶部依次为操作区、文件夹选择、三张统计卡片、筛选工具条；列表区域获得剩余高度。
- 去重合计卡集中显示当前筛选条数、去重前金额和去重后金额，按币种分隔。
- 列表列使用明确初始宽度与最小宽度。列标题分隔线可向左或向右拖动；窗口不足时出现水平滚动条。
- 省略显示的统计内容提供完整悬浮提示；表格单元格保留源文件/状态提示。

## 复制

- 表格使用单元格选择模式，支持不连续多选。
- `Ctrl+C` 与右键“复制选中内容”使用同一格式化逻辑。
- 同一行内以制表符分隔，不同行以换行分隔；不会补齐未选单元格，也不会加入表头、整行或整列。

## 清理操作

### 清空列表

只清理当前历史记录和界面列表，源关单、截图和所选文件夹保持不变。

### 清空文件夹

1. 必须先选择有效文件夹。
2. 磁盘根目录直接拒绝。
3. 只枚举当前层支持格式，不递归进入子文件夹。
4. 第一次确认显示文件数量、路径和处理范围。
5. 第二次确认再次说明文件将从当前目录移走。
6. 使用 Windows 回收站而非永久删除；成功文件同步移出识别列表，失败文件保留并报告。

## 状态表达

- 重复不仅使用红色，还显示“重复单号”文本，避免只靠颜色传达。
- “需关注/识别失败”在状态列显示文字，并通过单元格提示给出原因。
- OCR 进行时禁用“开始识别”，显示当前文件和总体进度，可取消。
- 危险操作使用独立红色按钮，与主操作“开始识别”在视觉上区分。

## 图标

应用图标以用户提供图形为造型参考重新绘制为方形构图，没有拉伸参考图。主资源为 1024×1024 PNG；Windows ICO 包含 16、24、32、48、64、128、256 像素七档。
