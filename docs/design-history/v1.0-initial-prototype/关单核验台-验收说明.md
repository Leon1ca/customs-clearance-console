# 关单核验台 v1.0 验收说明

## 交付形态

- 系统：Windows 10 / Windows 11 x64
- 使用方式：完整解压 ZIP 后，双击根目录的 `关单核验台.exe`
- 无需安装 .NET、Python、Tesseract、PDF 阅读器或数据库
- OCR：本地开源 Tesseract 5.4.0，含简体中文与英文模型

## 已实现功能

- 扫描指定文件夹当前层的 PDF、PNG、JPG、BMP、TIF/TIFF；每批上限 200 个
- 提取 6 个字段：报关单号、境外收货人、合同协议号、出境关别、目的国、关单总货值
- PDF 优先读取原始文字层；扫描件/图片自动使用 OCR
- 同一批次相同报关单号置顶标红
- 去重前/去重后金额同时展示；多个币种分别合计，不做汇率换算
- 搜索、状态筛选、20/50/100/200 条分页
- Edge 优先、Chrome 备用的在线核验；自动填写单号并尝试查询
- 人工验证完成后生成长截图，以报关单号命名；同名文件自动追加时间戳
- 清空历史不删除源文件和截图
- 异常文件保留在表格，并标记需关注/识别失败
