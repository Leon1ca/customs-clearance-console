# 关单核验台 v1.5.2

日期：2026-09-24。Windows 10 / 11 x64 便携版：完整解压后双击根目录 `关单核验台.exe`。

本版修复 v1.5.1 真机测试反馈的问题。此前变化见 [v1.5.1](release-notes-v1.5.1.md)、[v1.5.0](release-notes-v1.5.0.md)。

## 长截图

- **修复点击“长截图”提示“当前页面不是核验目标页，已忽略网页请求”**：
  - 官网地址是 `https://www.singlewindow.cn/#/publicInquiryDetail?id=pi4`，页面路由在 `#` 之后。浏览器调试接口报告页面地址时不带 `#` 部分，程序因此把页面记成 `https://www.singlewindow.cn/`，判定为非核验页，拒绝了所有截图请求。
  - 现在记录的地址包含 `#` 路由；单页应用在页面内切换路由时也会同步更新。
- 新增两项浏览器测试：
  - 以 `#/publicInquiryDetail` 打开仿官网页面；
  - 页面加载后再切换到该路由。

  两项测试在旧版上都会复现同一条拒绝提示，新版都能正常保存。

## 目的国识别

- 目的国取自“运抵国（地区）”，识别顺序：
  1. 标签上印的国别代码，如 `(DZA)`；
  2. 该栏中第一个国家名称；
  3. 该栏中的代码；
  4. 商品表“最终目的国（地区）”的代码。
- 国别表扩充为完整的 ISO 三字母代码与中文名（旧版只认 21 个国家，阿尔及利亚等不在其中）。
- 不再从整页任意位置找国名，避免收货人名称等无关文字被当成目的国。

## 表格

- 列宽始终贴满表格，最左和最右两列紧贴两边，出现滚动条时也一样。
- 拖动表头中两列之间的分隔线时**实时**调整，相邻两列此消彼长，总宽度不变；双击分隔线恢复默认列宽。
- 窗口拉伸时收货人、合同号、关别、目的国按比例伸缩，其余固定内容的列宽度不变。
- 窗口四边和四角都可以拖动调整大小；拉伸过程中整窗一次绘制，不再闪烁。

## 界面细节

- 右键“复制选中的内容 Ctrl+C”按文字实际宽度和缩放比例排版，不再显示不全。
- 按钮边框：
  - 修复“导出列表”上方的深色线条和边框过淡；
  - 修复“设置”“清理”边框粗细不均、底线不清；
  - 边框改为整像素绘制（100% 为 1 像素，150% 为 2 像素）。
- “每页 x 条”下拉：
  - 只显示 3 行；
  - 改用不抢占焦点的弹出列表，拉伸窗口后点击不会再让整个界面被其他窗口盖住。
- 筛选分段按内容宽度排列，“需关注”不再比其他分段宽；统计区与记录列表之间恢复设计稿的间距。
- 金额汇总暂无数据时为纯白背景，不再显示横线。

## 已知边界

- 真实单一窗口验证码必须人工输入，真实网站全流程仍需人工验收。若长截图仍失败，请提供卡片上的提示和 `%LocalAppData%\关单核验台\app.log`。
- 目的国规则用与反馈关单相同版式的合成页面验证。真实扫描件如仍识别错误，请告知显示的内容。
