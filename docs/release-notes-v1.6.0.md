# 关单核验台 v1.6.0 更新说明

## 新增

- 每条关单记录新增“详情”按钮。
- 金额详情按 PDF 页码和项号展示每一条识别总价、复核金额及校对结果。
- 不可靠金额仍显示在详情中供人工比对，但不会进入去重前/去重后合计。

## 识别修复

- 自动检测并纠正横向、倒置扫描页方向。
- 混合 PDF 只选择报关单页面，排除放行通知书、装货单、委托报关协议等附件。
- 多页关单金额区域扩展到页面底部，修复续页最后一项漏算。
- 国家名称按最长名称匹配并增加 ISO 代码映射，修复“印度尼西亚”被截断为“印度”。
- 双引擎金额冲突不再自动采用复核引擎数值。
- 当其中一个引擎完整读取价格表而另一个引擎明显缺失时，增加连续页面和表格结构校验作为安全降级规则。

## 验证

- 5 个已知异常 PDF、4 个唯一关单的自动回归通过。
- 测试批次去重前合计为 `CNY 1,264,978.33`，去重后合计为 `CNY 1,235,744.33`。
- 横向 5 页混合扫描件正确提取 10 条总价，合计 `CNY 989,148.63`。
