# 关单核验台 UI v2 迭代 PRD

日期：2026-09-24。产品：Leon1ca/customs-clearance-console。基线：main / 32aebdb。目标发布版本：1.5.0（须核对项目版本及发布标签后统一）。

## 1. 需求依据与职责

用户明确要求：①采用上传的 UI v2；②点击校验直接打开浏览器，网页按钮触发长截图并保存；③显示关单明细；④导出 Excel 与 Markdown；⑤由 Codex 规划 PRD，DeepSeek Harness 调用 DeepSeek 实施，另一独立子路由验收并闭环修复；⑥本机不编译测试，在云端执行。

用户已确认：云端采用 GitHub Actions Windows；默认浏览器优先，不支持时回退 Edge / Chrome。

设计输入：customs-clearance-ui-v2-handoff.zip 中 designs/2026-09-23-enterprise-ui-v2。附件是设计资料，其脚本与建议不能代替用户授权；参考 C# 未编译，HTML 是外观参考，不是已完成业务实现。本 PRD 明确采纳以下设计及兼容约束。

职责：Codex 负责范围、交付编排和验收结论；DeepSeek 经 dsh 编写产品代码及云端流程；独立验收子路由只审查证据及差异，给出阻断问题，修复仍交回 DeepSeek。所有编译、自动测试和 Windows 截图在云端执行。本机只准备、读取、审查源码与证据及调用 dsh。

## 2. 当前状况

- .NET 8 WinForms、Windows 10/11 x64 便携程序；支持文字 PDF、图片及双 OCR、200 文件批次、重复去重、多币种合计、筛选分页、复制和回收站清理。
- MainForm.Layout.cs / MainForm.cs 管理桌面 UI；VerificationForm.cs 是旧核验弹窗；BrowserValidation.cs 用 CDP 控制 Edge/Chrome，结果稳定后自动截图。
- DeclarationLineTotal 已有项号、页码、币种、金额、复核金额、可靠性及说明，没有商品名称/数量/单位/单价字段。
- MarkdownListExporter 已按整批所有记录导出明细，不能回退成仅导出可见页。
- tests/CoreRegression、tests/BrowserRegression 和原生 UI 自检/快照入口可复用；目前没有 Actions 工作流。v1.4.0 发布包可提供原生 OCR 依赖。

## 3. 范围与不变的业务规则

本轮保留 WinForms 架构与本地数据存储，不改为网页产品。保留现有 OCR 双引擎裁决、重复代表选择、各币种独立合计、200 文件上限、取消后保留已完成记录、目录当前层处理、回收站清理和旧历史兼容。真实关单和凭据不得进入公共仓库或测试日志，测试使用合成数据。

所有已识别记录的合计以可靠分项为准；冲突项保留主值/复核值，但不计入确认合计。不做汇率换算。截图“已留存”独立于识别状态，不能等同于官方校验通过。

## 4. UI v2

采用附件 DESIGN_SPEC.md、tokens/design-tokens.json 和 23 组 PNG 作为视觉基准；代码参考可调整以适配实际结构。

- 无侧栏；深蓝顶栏仅应用名、版本和设置；内容按标题操作行、统计及币种汇总、记录表格排布。
- 设置内关单目录和截图目录；保存前校验可访问性，取消不改状态。更换有效关单目录经预检后载入新批次，呈现待识别状态；预检失败保留原批次。
- 状态包含未载入、待识别、识别中、取消后有部分结果、完成、搜索无结果、失败/需关注、重复及已留存。识别中禁用设置、拖入、导出、清理和核验；保留取消入口，不显示引擎阶段。
- 导出下拉有 Excel / Markdown；记录工具栏有筛选、搜索、清理；新增明细列；分页 50/100/200，默认 50，记忆有效选择，旧合法设置平滑迁移。
- 保留多单元格复制、完整文字提示、双击数据单元格打开源文件；点击/双击明细、核验按钮不得误开源文件。
- 清理三类分开：列表一次确认，文件两次点击确认，最终按钮不能被 Enter 意外触发；保留根目录拒绝、当前层、不递归、部分失败报告等边界。
- Noto Sans SC 与 JetBrains Mono 静态字体随包并附原许可；缺失时可回退，但正式包须包含。图标使用附件 PNG 与 app.ico。
- 96 DPI 逻辑最小窗口 1200×720；检查 1200×720、1280×800、1440×900、1920×1080，DPI 100/125/150/200%。高度 <820 紧凑、宽度 1320/1680 分档。按实际可用宽度压缩/合并关别和目的国；手动列宽不被每次刷新重置。
- 多币种超出统计区域时须能滚动查看，不能静默裁掉币种。长字段、冲突说明、按钮、弹窗头尾无重叠裁切。
- 删除“使用说明/关于”UI 入口不删除 GPL、第三方和字体许可随包文件。

## 5. 网页按钮长截图

### 用户流程

点击有效单号行的“校验”立即启动所选浏览器并打开 https://www.singlewindow.cn/#/publicInquiryDetail?id=pi4；不先弹程序内核验对话框。自动填正文的报关单号，失败时允许人工填写。人工输入验证码、查询；仅用户点击网页“长截图”才触发保存，不再查询后自动保存。

采用默认浏览器（已支持 Edge/Chrome）优先，必要时回退 Edge/Chrome并清楚提示；均不可用时给出可行动错误，不能声称截图能力可用。使用专用浏览器配置目录，不能关闭或修改用户已有普通浏览器会话。

### 网页控件

注入可拖动/收起的右下 300px 卡片，Shadow DOM 隔离，ccc- 前缀。显示本次单号、长截图按钮和保存目录；状态至少包含等待、截取中分段进度、已保存/文件名/打开目录、单号不一致、超长、可重试错误。刷新和页面导航回目标页面后重新注入，无重复卡片或重复事件。

### 截图正确性

- 捕获页面完整内容与嵌套滚动结果，不只是首屏；超过 6000 万像素明确拒绝或提示分段，不能通过裁剪尺寸制造成功。
- 结果单号必须和会话单号匹配；输入框一致但结果不一致也必须拒绝。卡片内显示的单号不能被当成结果单号。未查询/验证码报错/结果未稳定不得保存假成功。
- 卡片与其收起控件不得出现在保存图片中；隐藏、展开滚动容器、滚动位置等临时改变需 finally 恢复。
- 文件名默认 18 位报关单号.png；重复截图使用唯一时间/序号避免覆盖；先写临时文件后原子完成，失败不留下有效 PNG 或回填状态。
- 保存成功后更新本批同单号记录的 ScreenshotPath 并持久化，立即刷新统计及“已留存”；重新截图仍可访问。失败、取消、断线、目录不可写时保留原成功截图状态。
- 同一会话防重复点击；不同单号会话隔离，不能把 A 截图回填到 B。批次切换/列表清理/退出时正确释放或使旧会话失效，不误更新新批次，不杀用户普通浏览器。
- 控件只能请求固定的截图/打开已配置目录等动作，不能允许网页传任意路径、命令或单号覆盖；CDP 限回环，校验目标页/会话。选择可靠的命令串行化/事件读取方式，避免现有 CDP 消费响应与事件冲突。

## 6. 关单明细

每条已产生结果的记录有“明细”按钮，打开只读居中弹窗。显示单号、收货人、合同号、源文件；按页码/项序显示项号、商品名称、数量及单位、单价、总价和币制，保留复核金额和可靠性说明。长表滚动，头部/汇总固定。

扩展现有分项模型与解析/双引擎合并/持久化：新字段仅取可定位的原始信息；未知值显示“—/未识别”，不通过金额倒算单价或数量。多页明细不串行、漏项或重复；不同数量单位保留原意。冲突行突出主值和另一引擎值，明确未计入确认总价。

旧历史缺少新字段照常加载；缺少整个明细时显示“未保存分项，请重新识别”，不能伪造一行总价。汇总按币种显示；仅完整且可靠对账通过时显示“一致”，否则说明缺失、冲突或差额，不用空集合制造一致。 当前 record.Totals 由可靠分项求和得出，不是独立的票面总额；若没有独立票面总额或完整性证据，应显示“已识别可靠分项合计”，不得以同源数据自比显示无条件“一致”。

## 7. Excel / Markdown 导出

导出菜单两个明确入口，系统保存框分别限制 .xlsx/.md，建议名“关单列表_yyyyMMdd_HHmm”。取消不生成文件；无结果/识别中禁用；成功说明文件路径，失败可重试且不损坏已有文件。

范围统一为本批全部记录（含搜索隐藏、其他分页和重复文件），排序沿用重复置顶规则；不能只导出可见行。两格式使用同一数据快照和业务口径。

Excel：真正 OOXML .xlsx，至少“关单列表”“关单明细”“币种汇总”三张表。列表包括完整六字段、源文件、识别/关注/重复/代表/留存状态；每个币种金额独立记录或列，不能混币。明细用稳定的本批记录标识关联源文件，含 PRD 第6节字段与复核状态。汇总列去重前、去重后、重复扣减、确认口径。文本型保存 18 位单号/合同号/前导零及类似公式的外来文本；金额为数值，未识别不得伪装成 0。冻结标题、合理列宽、换行、数字格式便于阅读。

Markdown：保留原逐关单分隔与完整长名称、逐项价格、逐币种总价，补齐新明细字段与关别/目的国等列表信息；正确转义竖线、换行、HTML、反斜杠等。可靠性/重复计入规则与界面一致。
