# 关单核验台 v1.4.0 更新说明

## 2026-09-09 整合发布

本次将当前全部本地迭代统一命名为 **v1.4.0**，不是恢复早期 1.4 的旧代码。主程序、启动器及使用说明版本均为 1.4.0。历史提交和设计稿保留用于追溯。

### 列表导出

- 在“开始识别”和“列表清理”之间新增“列表导出”，保存为 Markdown 文档。
- 本批每份关单分别列出报关单号、境外收货人、合同协议号、每项商品总价及逐币种关单总价，关单之间使用横线分隔。
- 表格完整保留长名称、协议号和数字，不截断；阅读器可按自身宽度换行或横向滚动。
- 导出覆盖全部分页、筛选隐藏的记录及重复文件；识别过程中或空列表时禁用。
- 冲突金额同时保留识别值与复核值，注明未计入合计；旧记录缺少分项时提示重新识别。
- 移除“详情”按钮和弹窗，逐项校对改用导出文档。

### 核验与界面改进

- 核验固定进入单一窗口的 pi4 报关单状态页面，并填写正文“报关单号”框。
- 用户输入验证码并点击查询后，自动检测稳定结果并保存长截图，无需返回软件确认；超时提供人工截图兜底。
- 五个主操作按钮使用统一扁平 PNG 图标，内含 24、32、48 像素资源。
- 右键菜单简化为“复制选中的内容  Ctrl+C”；总览标题字号大于金额，金额使用常规字重。
- 修复 PDF 文字层中低位下划线排列错位的问题；保留此前多页、多商品、币制拆行和双引擎金额校验修复。

### 使用方式与数据

- Windows 10/11 x64：完整解压便携包后运行根目录“关单核验台.exe”，无需预装 .NET 或 OCR 环境。
- 未改变本地历史数据的保存位置；所有本地关单、识别历史、日志和真实导出文档均不随发布包上传。
- 下文保留早期界面重构和清理边界说明。

## 界面重构

- 按新版矢量设计包重做窗口、命令栏、四项统计、记录面板、表格和分页。
- 支持 Windows 高 DPI 缩放、窄窗口省略提示、列宽双向拖动和选中单元格复制。
- 更换多分辨率应用图标，并在源码中保留完整设计交付包和设计令牌。

## 识别与核验

- “开始识别”只执行本地 OCR、重复单号检测、去重前/去重后逐币种合计，不访问核验网站。
- 识别结果逐条显示；取消或个别文件失败时保留已经完成的结果。
- 网站核验仍由用户逐条点击“校验”，人工完成网站验证后保存长截图。
- 移除浏览器选择框：优先使用 Windows 默认浏览器；默认浏览器不是 Edge/Chrome 时，为保留自动填写和长截图，自动回退到 Edge，其次 Chrome，并显示提示。

## 三类安全清理

- “列表清理”只清空识别记录，不删除任何文件。
- “关单清理”经过两次确认，仅处理当前关单文件夹当前层的 PDF/图片，并移入 Windows 回收站。
- “截图清理”仅处理当前截图文件夹中由程序记录、或按 18 位报关单号命名的 PNG 网页截图，并移入 Windows 回收站。
- 所有文件清理均不递归；磁盘根目录、用户根目录、桌面/文档根目录和程序目录会被安全拦截。

## 验证结果

- 通过编译、UI 契约、自适应截图和真实双引擎关单回归测试。
- 回归样本正确识别两份关单，金额分别为 CNY 371,520.00 和 USD 35,528.00。
