# 关单核验台 v1.4.0 更新说明

## 界面重构

- 按新版矢量设计包重做窗口、命令栏、四项统计、记录面板、表格和分页。
- 支持 Windows 高 DPI 缩放、窄窗口省略提示、列宽双向拖动和选中单元格复制。
- 更换多分辨率应用图标，并在源码中保留完整设计交付包和设计令牌。

## 识别与核验

- “开始识别”只执行本地 OCR、重复单号检测、去重前/去重后逐币种合计，不访问核验网站。
- 识别结果逐条显示；取消或个别文件失败时保留已经完成的结果。
- 网站核验仍由用户逐条点击“校验”，人工完成网站验证后保存长截图。
- 移除浏览器选择框：优先使用 Windows 默认浏览器；默认浏览器不是 Edge/Chrome 时，为保留自动填写和长截图，自动回退到 Edge，其次 Chrome，并显示提示。

## 三类安全清理

- “列表清理”只清空识别记录，不删除任何文件。
- “关单清理”经过两次确认，仅处理当前关单文件夹当前层的 PDF/图片，并移入 Windows 回收站。
- “截图清理”仅处理当前截图文件夹中由程序记录、或按 18 位报关单号命名的 PNG 网页截图，并移入 Windows 回收站。
- 所有文件清理均不递归；磁盘根目录、用户根目录、桌面/文档根目录和程序目录会被安全拦截。

## 验证结果

- 通过编译、UI 契约、自适应截图和真实双引擎关单回归测试。
- 回归样本正确识别两份关单，金额分别为 CNY 371,520.00 和 USD 35,528.00。
