# 关单核验台 v1.5.3

日期：2026-09-24。Windows 10 / 11 x64 便携版：完整解压后双击根目录 `关单核验台.exe`。

本版修复 v1.5.2 真机测试反馈的问题。此前变化见 [v1.5.2](release-notes-v1.5.2.md)。

## 识别：单引擎 + 规则复核（更快）

- **移除 Tesseract，只保留 PP-OCRv5**（RapidOCR / ONNX Runtime）：
  - 旧版每页运行 Tesseract 三次（方向检测、整页、稀疏补扫），再运行 PP-OCRv5 一次；现在每页只识别一次。
  - PP-OCRv5 对中文表格单据更准。反馈的关单只用它就能读对全部字段。
  - 便携包不再包含 Tesseract，体积更小。
- **规则复核替代第二引擎**。以下规则对 OCR 结果逐项检查，不符合时标为“需关注”并写明原因：
  - 每个商品的**数量 × 单价 = 总价**。数量可取申报、法定或第二数量；不符的分项不计入合计。
  - 表头的**报关单号**（预录入编号、海关编号、条码文字）必须一致。
  - **目的国**必须在国别表中。
  - **出境关别**必须是关区名称。
- **图片格式**：支持 PDF、PNG、JPG/JPEG/JFIF、BMP、TIF/TIFF、GIF、WEBP。
  - 多页 TIFF 逐页识别，只保留关单页。
  - 文件名或临时目录含中文也能正常读取。
- **页面方向**：横放（90° / 270°）或倒置（180°）的扫描件自动转正后识别。
- OCR 识别出的“4辆”“5020千克”这类数量带单位的文字，现在能正确读成数量和单位。

## 出境关别

- 修复关单识别后出境关别为空（例：出境关别 (5166) 南沙新港）。
- 新增兜底：框内的值未读出时，取表头“海关编号”后括号里的关区名，如（南沙新港）。
- 新增回归测试，使用反馈关单的真实 OCR 版式（名称、号码、金额已脱敏）。

## 长截图

- **修复卡片一直停在“截取中”**：
  - 每次截图最多 60 秒。超时后卡片显示“截图超时”，并写明卡在哪一步（例如“准备页面”“截取 3 段”），程序同时恢复页面，可以直接重试。
  - 卡片自带看门狗：程序长时间没有回应（例如程序已关闭、控制连接断开）时，卡片显示“截图无响应”，按钮恢复可点。
  - 截图正在进行时再点，卡片提示“上一次截图仍在进行”，不再无声等待。
  - 浏览器以不降速方式启动（后台定时器、被遮挡窗口不再被节流），避免浏览器窗口被程序窗口挡住时截图停住。
- 每一步的耗时写入 `app.log`（“截图步骤：…（xx ms）”）。如仍失败，请提供卡片提示和 `%LocalAppData%\关单核验台\app.log`，可以直接定位卡住的步骤。
- 新增浏览器测试：模拟截图中途浏览器无响应，要求 3 秒时限内结束、卡片显示原因、不生成文件，并且重试能正常保存。

## 界面

- **关单总货值列**拉窄时，币种不再叠在数字上；放不下时整体显示省略号，与其他列一致。
- **列表表头**各标题之间加入短竖线分隔。
- **弹窗与下拉**：
  - 覆盖设置、确认、清理、明细弹窗，“每页 x 条”下拉，导出/清理菜单和右键复制菜单；
  - 去掉系统投影（投影偏在右下，使右边和下边的边框显得更粗）；
  - 边框改为沿窗口外形精确描一圈：100% 缩放下 1 像素，150% 下 2 像素，四边和圆角粗细一致。
- **拖动窗口**：只在拉伸窗口大小时启用整窗合成绘制；拖动标题栏移动窗口不再额外重绘，移动更顺滑。

## 验证

- 核心回归 92 项，新增：
  - 真实关单版式：出境关别、目的国、总价；
  - 各条规则的正反例：总价、单价、单号一处读错时都标为需关注。
- 浏览器 E2E 33 项全部通过（新增“截图中途无响应”一项）。
- Windows CI 新增 **OCR 端到端自检**（`--ocr-self-test`），用 PP-OCRv5 实际识别以下文件，逐一核对单号、出境关别、目的国、合同号、总价与状态：
  - 同一张关单另存的 PNG、JPG、BMP、WEBP；
  - 两页 TIFF；
  - 旋转 90°、180°、270° 的图片；
  - 无文字层的扫描 PDF。

## 已知边界

- 真实单一窗口验证码必须人工输入，真实网站全流程仍需人工验收。
- v1.5.2 及以前保存的记录仍显示原来的“双引擎”结论；重新识别后改为规则复核结论。
