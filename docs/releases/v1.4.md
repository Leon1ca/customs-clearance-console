# v1.4 更新说明

发布日期：2026-08-25

## 稳定性

- 修复“记录筛选”下拉关闭后被提前销毁、随后点击搜索框或再次展开时触发闪退的问题。
- 下拉弹层改为在控件生命周期内复用，并加入连续打开、关闭和焦点切换回归测试。

## 界面

- 目录设置、关单清理、截图清理、开始识别、列表清理五个按钮改为完全自绘，严格使用原型的底色、1px 边框、7px 圆角、24px 图标和交互状态。
- 关单总览内容整体下移并重新垂直居中；金额使用常规字重，仅无金额时的“—”使用粗体并校正位置。
- 目录设置改为 780px 自绘窗口：12px 圆角、设计稿标题栏、56px 路径框、浅蓝目录按钮、内联错误提示和半透明遮罩。
- 窗口最大化后，标题栏按钮切换为“还原窗口”双方框图标；恢复普通窗口后自动切回单方框最大化图标，并同步无障碍名称。
- 总货值解析增加价格列几何约束和币制容错：金额被拆成多个 OCR 片段时会自动重组；“美元”被识别成“美”或“上米”时，可在关单价格列内安全恢复为 USD。
- “记录筛选/每页显示”弹层改为独立自绘窗口，关闭时只隐藏并安全复用，修复 WinForms 菜单过滤器访问已释放 `ToolStripDropDown` 导致的 `0xe0434352` 崩溃。
- 标题栏“还原窗口”双方框不再通过填充覆盖后框，改为一次性绘制可见线段；上下边线使用相同像素网格和笔宽。
- 关单清理、截图清理、列表清理统一使用 640px 自绘确认框，不再调用 Windows 默认确认框。

## 数据安全

- 关单与截图清理仍只处理规定范围并移入 Windows 回收站；弹窗文案明确说明这一行为。
- 列表清理只移除界面和本地状态记录，不删除源关单文件。

## 兼容性

- Windows 10 / Windows 11 x64。
- 完整解压后直接运行，不要求预装 .NET、Python、OCR 或数据库。
