# v1.5.0 更新说明

发布日期：2026-08-25

## 界面

- 严格按矢量原型重新标定标题栏：40px 应用图标、25px 标题、16px 最小化/最大化/关闭图形与 56px 点击热区。
- 目录设置、关单清理、截图清理、开始识别、列表清理恢复为原型的 24px 矢量图标和按钮配色。
- 本批关单、重复单号、去重前总价、去重后总价使用原型图标和色板；移除“总共关单数量”“重复单号数量”“按币种分别合计”等说明文字。
- 筛选区使用原型中的“单号搜索 / 记录筛选 / 每页显示”，控件高度统一为 52px；搜索框加入 24px 搜索图标，下拉箭头、选中态和菜单改为自绘。
- 多币种金额继续按币种逐行显示，不换算汇率。
- 以 1586×992 和 1365×855 两种窗口尺寸完成截图复核。

## 在线校验

- 校验地址固定为 `https://www.singlewindow.cn/#/publicInquiryDetail?id=pi4`。
- 自动填写同时检查页面正文、子框架与开放式组件，使用网页原生输入事件写入对应的“报关单号”输入框。
- 程序不会填写验证码，也不会替用户点击“查询”；人工验证规则不变。

## 兼容性

- Windows 10 / Windows 11 x64。
- 完整解压后直接运行，不要求预装 .NET、Python、OCR 或数据库。
