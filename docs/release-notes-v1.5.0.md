# 关单核验台 v1.5.0（UI v2 迭代）

日期：2026-09-24。Windows 10 / 11 x64 便携版：完整解压后双击根目录 `关单核验台.exe`，无需预装 .NET、Python 或 OCR。

## 主要变化

- **界面 v2**：按 `designs/2026-09-23-enterprise-ui-v2` 复刻。深蓝顶栏（应用名 / 版本 / 设置）、标题行状态标签、2×2 统计面板、按币种金额汇总（份数 / 去重前 / 去重后 / 重复扣减）、记录工具栏（筛选分段 / 搜索 / 清理下拉）、真实表格列与分页（50 / 100 / 200，默认 50）。覆盖未载入、待识别、识别中、识别完成、搜索无结果、重复、需关注、已留存状态。
- **响应式布局**：1200×720 / 1280×800 / 1440×900 / 1920×1080 四档，高度 < 820 紧凑档，宽度 1320 / 1680 分档；1200 宽自动合并“出境关别 / 目的国”列，手动列宽在刷新后保留。
- **网页按钮手动长截图**：点击“校验”直接以默认（必要时回退 Edge / Chrome）浏览器打开单一窗口 pi4 页面并注入右下角截图卡片；不再弹出程序内核验对话框，也不再自动截图。用户在网页输入验证码并查询后，点击卡片“长截图”保存整页（含嵌套滚动），超过 6000 万像素明确拒绝而不是裁切，控件不入图，页面在 finally 中恢复，文件先写临时文件再原子替换，成功后回填本批同单号记录。
- **CDP 可靠性**：DevTools 客户端改为单一接收循环 + 命令序号关联 + 事件订阅，命令与事件不再互相消费；网页卡片通过 `Runtime.addBinding` 请求截图，同一会话防重复点击，跨批次 / 列表清理 / 退出时使旧会话失效。
- **关单明细**：新增商品名称、数量、单位、单价字段（仅取可定位原始信息，未知保持空，不通过金额倒算）；新增只读明细弹窗，按页码 / 项序展示，长表滚动、头尾固定，冲突项高亮并显示另一引擎值。
- **导出**：导出下拉提供 Excel / Markdown 两个入口。Excel 为真正的 OOXML `.xlsx`，包含“关单列表”“关单明细”“币种汇总”三张表，18 位编号 / 合同号 / 前导零 / 公式型外来文本按文本保存，金额为数值，未识别保持空白；Markdown 保留原逐关单分隔与完整长名称并补齐新字段。两者使用同一整批快照（含搜索隐藏、其他分页与重复文件）。
- **字体与图标**：随包 Noto Sans SC（Google Fonts，SIL OFL 1.1）与 JetBrains Mono（SIL OFL 1.1）及原许可；UI v2 PNG 图标按 DPI 选择 16 / 24 / 32 / 48。

## 稳定性修复

- **网页长截图**：修复失败后恢复或连续快速重试时，点击“查询”偶尔未被识别、截图卡片一直提示“查询结果尚未确认”的问题（跨进程页面的地址判断和查询监听绑定）。修复负载较高时截图下半部分可能空白的问题：截图前确认页面已完整绘制，截图后再复核，空白则重截，仍失败则拒绝保存而不是保存空白图。浏览器命令增加超时，不会因浏览器无响应长期卡住截图。
- **浏览器**：关闭核验浏览器后不再反复尝试恢复；每次核验遗留的浏览器临时目录会被清理。
- **数据安全**：识别历史先完整写入磁盘再替换；文件损坏时先备份，不会在下次保存时被空记录覆盖。
- **导出**：字段中含 PDF 控制字符时自动剔除，不再导致整批 Excel 导出失败。
- **启动器**：以 `\` 结尾的目录参数不再吞掉后续参数。
- **性能与长期运行**：表格重绘不再重复读取图标，行样式共享，修复字体、画笔和窗口区域资源泄漏；拖拽文件时不再反复检查磁盘；日志超过 5 MB 自动轮转；启动时清理残留的 OCR 临时目录。
